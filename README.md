### 🏭 [FDD – 5-Agent Fault Detection & Diagnosis System](https://github.com/NarendraReddy077/fdd-agent)

**LangGraph · LangChain · Python · AI Agents · Tool Calling**

An agentic AI pipeline developed during my Siemens internship to analyze building operational data and assist with equipment fault diagnosis.

The system uses five specialized agents orchestrated through LangGraph:

- **Investigation Agent:** Determines whether an intervention is required.
- **Root-Cause Analysis Agent:** Investigates overrides, delays, occupancy issues, and operational anomalies.
- **OPEX Estimation Agent:** Calculates event-level and annualized energy impacts.
- **Action Recommendation Agent:** Suggests corrective actions and responsible owners.
- **Verification Agent:** Validates resolution criteria and generates standardized diagnostic reports.

**Engineering Highlights:**
- Multi-agent orchestration and state management
- Structured outputs and schema normalization
- Tool calling and domain-specific reasoning
- Operational data integration with LLM workflows
- Rule-based validation alongside AI-generated recommendations
